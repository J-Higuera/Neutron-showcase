# Credits — Triple Play Studio v2 (React rebuild)

- **Stack:** React 19, TypeScript, Vite 8, Tailwind CSS 4, Framer Motion 12
  (all MIT-licensed, installed with owner approval 2026-08-19). Built as a
  static SPA; `netlify.toml` + `netlify/functions/board.mjs` add a real Node.js
  serverless endpoint and captured form submissions when deployed on Netlify.
- **Imagery:** None. Every interface shown (the Quayside quote builder, the
  Bramble phone, the Ledgerline payment run, the scoreboards, the split-flap
  studio board) is a hand-authored, operable React component. No stock
  photography, no screenshots, nothing hotlinked.
- **Fonts:** Instrument Serif, Geist, and Geist Mono via Google Fonts (SIL OFL).
- All companies, people, products, and numbers on the page are fictional.
